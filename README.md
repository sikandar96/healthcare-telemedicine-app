# Healthcare Telemedicine App

A React and Vite frontend for the healthcare telemedicine application.

## Local development

From the project directory, install dependencies and start the development server:

```bash
npm install
npm start
```

The app will be available at the local URL printed by Vite, typically `http://localhost:5173`.

`npm run dev` is an equivalent development command. The `npm start` alias is included for compatibility with the original project documentation.

## Available scripts

| Command | Purpose |
| --- | --- |
| `npm start` | Start the Vite development server. |
| `npm run dev` | Start the Vite development server. |
| `npm run build` | Create a production build in `dist/`. |
| `npm run preview` | Serve the production build locally for verification. |
